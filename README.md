# ISM6427 – Weather App

A simple, Apple-style glassmorphic weather app powered by the free [Open-Meteo API](https://open-meteo.com/) (no API key needed). Defaults to Boca Raton, FL; search any city with the search bar.

## Files
- `index.html` – page layout
- `style.css` – glassmorphism styling
- `app.js` – fetches forecast + geocoding data from Open-Meteo

## Deploy to Netlify
It's a plain static site with no build step. On Netlify, leave the build command blank and set the publish directory to the repo root (`.`), or just drag and drop the folder.
